# Flappy Bird - Python/Pygame Edition 🐦

A fully playable, object-oriented clone of the classic Flappy Bird game, built completely from scratch using Python and Pygame. 

## ✨ Features
* **Custom Physics Engine:** Smooth gravity, velocity, and jump mechanics.
* **Infinite Procedural Generation:** Pipes spawn with randomized gaps and automatically cull off-screen for memory management.
* **State Machine:** Clean transitions between Start Screen, Active Gameplay, and Game Over states.
* **Persistent High Scores:** Saves your best score automatically using local file handling.
* **Parallax Scrolling & Rotation:** Endless scrolling background and dynamic bird rotation based on velocity.
* **Graceful Asset Loading:** Fallback colored rectangles if sprite or audio files are missing.

## 🚀 How to Play
1. Ensure you have Python installed.
2. Install Pygame: `pip install pygame`
3. Clone this repository and run the main file: `python main.py`
4. **Controls:** Press **SPACE** or **Left Mouse Button** to flap!
